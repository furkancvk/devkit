# Security

Skills are instructions that run with your agent's permissions, and this kit ships a hook that runs at session start. If you find a way the kit could leak data, run something unexpected, or be used to inject instructions, please report it privately through GitHub's "Report a vulnerability" button on the Security tab of this repository rather than in a public issue.

What the kit runs is listed under "What runs on your machine" in the README. Third-party content is pinned to exact commits listed in `THIRD_PARTY.md`.
